# Physics 2111 Study Guide

Static site. No build step.

- `index.html` study guide hub
- `ninja-lab.html` interactive simulations
- `print.html` printable version with solutions

## Deploy on GitHub Pages
1. Push the contents of this folder to the repo root.
2. Settings > Pages > Source: Deploy from a branch > `main` / `(root)`.
3. Site URL: `https://<user>.github.io/<repo>/`

Needs internet for KaTeX, PDF.js and Google Fonts (loaded from CDNs).
